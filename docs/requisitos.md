# Requisitos del proyecto

## Base
- Juego 2D con dinámicas de Hollow Knight y The Binding of Isaac.
- Vista de plataformas (estilo Hollow Knight).
- Mapa pequeño de momento, ampliable más adelante.

## Jugabilidad
- Mínimo 3 armas básicas para empezar la run.
- 10 objetos coleccionables con sinergias entre ellos.
- Los objetos están en **salas del tesoro** (no aparecen al limpiar cada sala).
- Salto fluido y natural, con posibilidad de saltar justo al tocar el suelo.
- Varias estructuras destruibles.

## Mundo
- Sistema de generación de salas que reutiliza salas predefinidas y estructuras que modifican el escenario.

## Estética (por ahora mínima)
- Héroe = punto azul
- Enemigos = puntos rojos
- Escenario = solo líneas de márgenes
- Menú sencillo

## Técnica
- Código adaptado para facilitar una futura migración a Unity u otro motor (objetivo tipo Hollow Knight, Isaac, Hades).

## Documentación
- Informe completo y profesional: guía, acta de constitución, análisis de sector, propuesta de proyecto y documentos relacionados.
